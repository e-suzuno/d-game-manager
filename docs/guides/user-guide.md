# 使い方

購入した個人開発ゲーム（.exe 入りフォルダ）をローカルで管理するデスクトップアプリ。

## 基本の流れ

1. **取り込む** — 左下「フォルダを取り込む」→ フォルダを選択、または**フォルダをドロップゾーンへドラッグ&ドロップ**（複数可）。ゲーム1本のフォルダでも、複数ゲームが入った親フォルダ（例: `D:\DL`）でも OK。配下の .exe を自動検出し、制作ツール（RPGツクール / Unity / Godot / WOLF RPG / ティラノ）を判別して属性として記録する（判別できなければ「未判別」）。exe にアイコンがあれば抽出して既定カバーにする
2. **整理する** — 行 / カードをクリックして詳細ドロワーを開き、タグを追加（Enter で新規、候補チップで既存から）。タグのラベルをクリックすると 9 色から色を変更できる。タグの語彙そのもの（リネーム・色・ジャンル⇄その他の変換・削除・新規登録）は**タグ管理**（左ナビ「タグで絞り込み」右の「管理」、または設定の「タグ（ジャンル）を管理」）でまとめて編集でき、変更はすべてのゲームに反映される
3. **見つける** — 検索（タイトル・タグ・制作ツール）、左ナビのビュー（すべて / お気に入り / 未整理 / 見つからない）、タグ絞り込み、制作ツール絞り込み（複数選択 = OR）、ツールバーの並び替え・グループ化を組み合わせる。タグは**ジャンル同士・その他タグ同士が OR、ジャンル群とその他タグ群の間が AND**（例: ジャンル「RPG」「ADV」+ タグ「クリア」= RPG か ADV のうちクリア済みのもの）。フィルタは ビュー → タグ(ジャンルOR・その他OR・両群間AND) → 制作ツール(OR) → 検索 の順に適用される。ツールバーの「制作ツール」「タグ」ボタンからも同じフィルタを操作できる
4. **起動する** — 行の ▷ ボタン、またはドロワーの「起動」。「フォルダ」でエクスプローラー表示

## ゲームを削除・移動したとき

アプリは起動時に、登録済みゲームのフォルダと実行ファイルが実際にあるかを確認する。見つからないものには一覧（テーブル / ギャラリー）に「見つかりません」バッジが付き、左ナビに**「見つからない」ビュー**が現れる（該当が0本のときはこの行は出ない）。**アプリが勝手に登録を消すことはない**（外付けドライブを繋いでいないだけの場合に、タグやお気に入りを失わせないため）。

対処は状況によって2通り:

- **移動・リネームしただけ** → ドロワーの警告内「フォルダを指定し直す」で新しいフォルダを選ぶ。実行ファイルは選んだフォルダから自動で再検出され、**タイトル・タグ・お気に入り・カバー画像はそのまま**引き継がれる（フォルダはゲームフォルダ自体を選ぶ。同じフォルダを選び直せば「exe だけ名前が変わった」場合の修復にもなる）
- **ゲーム本体を削除した** → ドロワー最下部「ライブラリから削除」で一覧から外す。まとめて片付けるなら「設定」→「保存先の整合性」→「保存先を確認する」で見つからないゲームの一覧が出るので、残したいもののチェックを外して「選択した N 本をライブラリから削除」

外付けドライブやクラウド同期のフォルダに置いたゲームは、**接続した状態で確認する**こと（未接続だと「見つからない」扱いになる。接続し直してアプリを起動すればバッジは消える）。

## カスタマイズ

- **タイトル変更**: ドロワーのタイトル（鉛筆アイコン）をクリック → 入力 → Enter か ✓。フォルダ名は変わらない
- **カバー画像**: ドロワーのカバー左上「画像を変更」で好きな画像（スクショ等）を設定。↺ で初期に戻る（exe から抽出したアイコンカバーも ↺ でグラデーションに戻せる）
- **お気に入り**: 一覧の ☆ をクリック
- **削除（登録解除）**: ドロワー最下部「ライブラリから削除」→ 確認して「削除する」。**ゲーム本体のフォルダ・ファイルは削除されない**（ライブラリの登録が消えるだけ。再取り込みも可能）
- **全データ消去**: 左ナビ下部「設定」→ 危険な操作「すべてのデータを消去…」→ 確認欄に「消去」と入力して「完全に消去する」（二段階確認）。登録ゲーム・タグ・お気に入り・カバー画像などアプリ内データがすべて消え初期状態に戻る。**ゲーム本体のフォルダやファイルには一切影響しない**。この操作は取り消せない

## データの保存場所

| OS | 場所 |
|---|---|
| Windows | `%AppData%\d-game-manager\`（`library.db` + `covers\`） |
| Linux / WSL | `~/.config/d-game-manager/` |

- アンインストール時に「ライブラリのデータも削除しますか?」と確認される。「いいえ」ならデータは残り、再インストールで復元される
- ゲーム本体のフォルダをアプリが変更・削除することはない

## 仕様上の注意

- プレイ時間・進行状況の自動記録はしない（プロセス監視をしない方針）。進行状況は「プレイ中」「クリア」などの手動タグで管理する
- タグの軸（ジャンル / その他）はタグ作成時に決まり、タグ管理の ⇄（性質変換）で後から変更できる。ドロワーから手動追加したタグは「その他」になる。制作ツールはタグではなく属性として扱う
- タグ管理での削除は語彙ごと消える（全ゲームから外れる）。ドロワーでゲームからタグを外すだけなら語彙（色・軸）は残る
- 同じフォルダの二重登録はできない（取り込み候補から自動除外）。保存先の指定し直しでも、他のゲームが使っているフォルダは選べない
- 実体の有無はアプリ起動時と「保存先を確認する」の実行時にだけ調べる（常時監視はしない）。アプリを開いたままゲームフォルダを消した場合は、確認を実行するか再起動すると反映される

## 既知の制限

- exe のアイコン抽出は取り込み時のみ（既に登録済みのゲームには遡って適用されない）
- WSL 開発環境での日本語入力・タイトルバー表示の制限は [`development-setup.md`](development-setup.md) 参照
