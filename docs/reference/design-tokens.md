# デザイントークン

## タグの9色パレット

各色は `{ text, bg }` の組。タグチップは `color:<text>; background:<bg>` で描画する。

| key | text | bg |
|---|---|---|
| blue | `#1e40af` | `#dbeafe` |
| teal | `#0f766e` | `#ccfbf1` |
| violet | `#5b21b6` | `#ede9fe` |
| rose | `#9f1239` | `#ffe4e6` |
| amber | `#92400e` | `#fef3c7` |
| green | `#166534` | `#dcfce7` |
| cyan | `#155e75` | `#cffafe` |
| slate | `#334155` | `#e2e8f0` |
| gray | `#57534e` | `#eceae4` |

**既定色は軸で決まる**: ジャンル → `blue` / その他 → `gray`。色はタグ名ごとにグローバルで、`tags.color` にパレットキーとして保存する（空文字＝軸の既定色）。

`teal` はパレットから選べる9色の一つとして残っているが、**軸の既定色としては使われない**（制作ツール属性化で tool 軸が廃止されたため）。

## Typography

- **UI**: Manrope（400–800）＋ Noto Sans JP（400 / 500 / 700） → `font-family:'Manrope','Noto Sans JP',sans-serif`
- **等幅**（パス・数値・件数・日付）: JetBrains Mono（400 / 500）
- フォントは `@fontsource-variable` でバンドルする（Google Fonts への実行時アクセスはしない）
