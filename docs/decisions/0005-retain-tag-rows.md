# 0005 タグ行は孤児になっても温存する

**決定日**: 2026-07-21（コードレビューを受けて [`0004`](0004-delete-orphan-tags.md) を置き換え）

## 決定

**タグ行が消えるのは、タグ管理からの明示的な削除（`DeleteTag`）のときだけ。** ゲームを削除しても、ゲームからタグを外しても、タグ行は残る。

同じレビューで次の2点も決めた。

- **検索・サジェストは大文字小文字を区別しない**
- **グループ化では、同一軸に複数タグを持つゲームは複数のグループに重複して現れる**

## 背景

孤児削除方式（[`0004`](0004-delete-orphan-tags.md)）では、最後の1件からタグを外した瞬間にユーザーが設定した色と軸まで失われ、同じ名前で付け直しても復元できなかった。

## 帰結

- 色と軸は「そのタグに対する設定」として、付与状況とは独立に保たれる。付け直せば元の色で戻る
- **タグを語彙として先行登録できるようになった** — どのゲームにも付いていない（count 0 の）タグが正当な状態になったため、タグ管理モーダルからの新規登録が成立する
- サイドナビのタグ候補は**全語彙基準**で並ぶ（count 0 も表示）。孤児削除方式ならノイズだったものが、意図的な語彙管理の結果になった
- 使わなくなったタグは自然には消えないので、**掃除の導線を UI として用意する必要がある**（タグ管理モーダルの削除）
- グループ化の重複表示は、1ゲームが同一軸に複数タグを持てるモデルの素直な帰結として受け入れた
