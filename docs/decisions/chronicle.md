## この表の「デザイン v2 / v3」という呼称について

**原文をそのまま引き継いでいるため、撤回した世代番号の呼称が残っている。** 実体は次のとおり。

- 「デザイン v2 受領」 → **調整版ハンドオフ**ではなく、**基本ハンドオフへの追補**を指している（当時 v1 ディレクトリに上書きで反映された）
- 「デザイン v3 受領・実装」 → タイトル編集とカバー画像変更は**基本ハンドオフ**に含まれる機能

番号が4系統でずれている経緯は [`docs-policy.md`](../docs-policy.md) を参照。**新しい文書では番号で呼ばない。**
