# 0004 孤児になったタグ行はタグ解除時に削除する（撤回）

**決定日**: 2026-07-21 / **撤回日**: 2026-07-21（同日のコードレビュー）

> **この決定は撤回された。** 現行の方針は [`0005-retain-tag-rows.md`](0005-retain-tag-rows.md)。

## 当時の決定

タグは `name` 一意 ＋ `axis`（genre / tool / other）で持つ。**ゲームからタグを解除して、どのゲームからも参照されなくなったタグ行は削除する。** ただしゲームを削除した場合はタグ行を温存する。

## 当時の考え

使われていないタグが `ListTags` に残り続けると、サイドナビの候補やフィルタ軸にノイズが溜まる。参照が無くなった時点で消せば、テーブルが自然に掃除される。

## なぜ撤回したか

タグ行には**ユーザーが設定した色と軸**が乗っている。孤児削除方式では、最後の1件からタグを外した瞬間にその設定ごと消えてしまい、**同じ名前で付け直しても色が戻らない**。

「今どのゲームにも付いていない」ことと「そのタグに対する設定が不要になった」ことは別の話だった。加えて、タグを語彙として先行登録する機能（タグ管理モーダルからの新規登録）と根本的に両立しない — 登録した瞬間に孤児なので消えることになる。

なお `axis` の候補に `tool` があるのもこの時点の名残で、こちらは制作ツールの属性化で別途撤回されている（[`tool-attribute.md`](../specifications/tool-attribute.md)）。
