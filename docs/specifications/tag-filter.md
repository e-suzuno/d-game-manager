# 絞り込みの AND/OR 規則と適用順

> **Not:** 全条件 AND の一括評価ではない。同じ群の中は OR で評価する。

## タグの評価

- **ジャンル × ジャンル = OR** — 複数選択したどれかに一致すれば表示
- **その他タグ × その他タグ = OR**
- **ジャンル群 と その他タグ群 の間 = AND**

```
tagOk(game) =
  (selectedGenres.length === 0    || selectedGenres.some(g => game.labels.includes(g)))
  &&
  (selectedOtherTags.length === 0 || selectedOtherTags.some(t => game.labels.includes(t)))
```

**選択が空の群は条件なし**として扱う（その群では絞り込まない）。

この形にしたのは、同じ軸の中での複数選択は「どれか」を意味し、違う軸をまたぐ選択は「かつ」を意味するのが自然だからである。たとえば「ジャンルが RPG または ADV で、かつ 進行状況が クリア済み」という絞り込みが1回の操作でできる。

## 制作ツールの評価

**完全に独立したフィルタ**で、複数選択は **OR**。1ゲームは1ツールしか持たないため AND では常に0件になる（[`tool-attribute.md`](tool-attribute.md)）。

タグとは **AND で併用**する。

## 適用順

```
ビュー → タグ → 制作ツール → 検索 → 並び替え → グループ
```

- **ビュー** — `すべてのゲーム` / `お気に入り` / `未整理（タグなし）`（＋実体不明があるとき `見つからない`）
- **検索** — タイトルとタグ名の部分一致。**大文字小文字を区別しない**
- **統計は絞り込みに連動しない。** 総数 / 総容量 / お気に入り / 未整理はいずれも**全ゲーム基準**で算出する

## 状態の共有

サイドナビの絞り込みとツールバーのポップオーバーは**同一の状態を共有**する。閲覧用（サイドナビ）と即時アクセス用（ツールバー）の2入口を意図的に両方提供している。

ツールバーは**「制作ツール」ボタンと「タグ」ボタンに分かれており**、それぞれ独立した件数バッジと「解除」を持つ。属性とタグは性質が違うものなので1つのメニューに混ぜない（調整版ハンドオフ 変更点6）。

UI の詳細は [`library-screen.md`](library-screen.md) の「ツールバー」と「絞り込みの評価順と AND/OR 規則」を参照。
