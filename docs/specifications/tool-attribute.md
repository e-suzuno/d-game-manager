# 制作ツールは一級属性として扱う

制作ツール（RPGツクール / Unity / Godot / WOLF RPG / ティラノ / GameMaker など）は**タグではなく `Game.tool` の属性**として持つ。

> **Not:** 制作ツールはタグではない。タグ軸に `tool` は存在しない。

## 規則

- **1ゲームは1ツール。** `games.tool` に文字列で保持する
- **既定値は「未判別」。** 空文字は保存時に「未判別」へ正規化する
- **「未判別」は一級の状態**であり、欠損値や null ではない。バッジ・フィルタ・グループのいずれにも「未判別」という選択肢が現れる
- **スキャンで推定できたものは確定値**として保存する。推定できなかったものだけ「未判別」になる
- **未判別から確定への変更は詳細ドロワー**で行う（`SetTool`）。ここが主動線
- ドロワーの選択肢は `["未判別", <既定ツール6種>, <ライブラリ内に存在する全ツール>]` を重複排除したもの。**既定ツール6種** = `RPGツクール` / `Unity` / `WOLF RPG` / `ティラノ` / `GameMaker` / `Godot`
- **タグ一覧に制作ツールを含めない。** タグ列・タグ編集ブロック・タグフィルタのいずれからも除外する

## なぜ属性にしたか

タグは「1ゲームに複数付き、ユーザーが自由に増やす」ものだが、制作ツールは「1ゲームに1つで、値の集合がほぼ固定」という性質が逆になっている。タグの多対多モデルに載せると、専用カラムでの並び替え・専用フィルタ・単一選択の編集 UI がどれも自然に作れなかった。

「未判別」を欠損ではなく一級の状態にしたのは、**判別できなかったこと自体が利用者に伝える価値のある情報**だからである。空欄だと「まだスキャンしていない」のか「判別できなかった」のか区別できず、確定させる導線も作れない。

## フィルタ・グループでの扱い

- **フィルタは複数選択で OR**（1ゲーム=1ツールなので AND では常に0件になる）。タグとは AND で併用する。詳細は [`tag-filter.md`](tag-filter.md)
- サイドナビの制作ツールセクションは**既定で折りたたみ**
- **グループ化の選択肢に残す。** 未判別のゲームは「未判別」グループに入る
