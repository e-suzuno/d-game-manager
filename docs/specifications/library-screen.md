# ライブラリ画面 UI 仕様（現行）

所有ゲームの一覧・検索・絞り込み・並び替え・グループ化、詳細の確認と編集、フォルダ取り込み、ゲームの起動を担うメイン画面。方向性は **2A「コレクションDB」**（Notion / Airtable 的な明るいワークスペース型の UI）。

この文書は**基本ハンドオフと調整版ハンドオフを統合した現行仕様**で、単体で読めば足りる。2つの原本はリポジトリに残していない（基本ハンドオフには撤回済みの仕様が含まれており、撤回内容は frontmatter の `not:` に構造化してある）。

> **Not:** 制作ツールはタグではない。タグ軸は ジャンル / その他タグ の2軸で、制作ツールは `Game.tool` の一級属性。またタグフィルタは全条件 AND ではない（ジャンル同士 OR・その他タグ同士 OR・両群間 AND）。詳しくは frontmatter の `not:` を参照。

色・タイポグラフィ・影・角丸の値は [`design-tokens.md`](../reference/design-tokens.md) にまとめてある。ここでは構造・寸法・挙動を扱う。**hi-fi デザインなのでピクセル単位で再現する。**

## 全体レイアウト

横並び2カラム。

- **左: サイドナビ** — 固定幅 `246px`、右境界 1px、パディング `54px 14px 16px`（上部はアプリのタイトルバー想定の余白）
- **右: メインエリア** — `flex:1`、縦積みで ヘッダー → 統計バー → ツールバー → テーブル/ギャラリー

オーバーレイは3種。右からスライドインする**詳細ドロワー**（幅 `400px`）、中央の**モーダル**（取り込み・タグ管理は `560px`、設定は `520px`）、下部中央の**トースト通知**。

## サイドナビ

上から順に、ロゴ行 → ビュー → 制作ツール（属性）→ タグで絞り込み → 設定ボタン → 取り込みボタン。

### ロゴ行

`28×28` 角丸 `8px` の四角（アクセント背景・白「◈」）＋ 製品名「d-game-manager」(weight 800, 15px) ＋ サブ「ローカルコレクション」(11px)。

### ビュー（3項目・クリックで切替）

`すべてのゲーム` / `お気に入り` / `未整理（タグなし）`

行は `display:flex; justify-content:space-between; padding:8px 11px; border-radius:9px; font-size:14px`。件数は右寄せで等幅フォント。アクティブ行は文字 weight 600 ＋ 淡いアクセント背景 ＋ 件数がアクセント色になる。

なお実体が見つからないゲームがある場合の「見つからない」ビューについては [`storage-integrity.md`](storage-integrity.md) を参照（該当0件なら非表示）。

### 制作ツール（属性）セクション

**既定で折りたたみ**のアコーディオン。見出しクリックで開閉し、選択中は見出しに件数バッジを出す。

値は**ピル**で並べ、**複数選択＝OR**（1ゲームは1ツールしか持たないため）。角丸 `8px`、`font-size:12.5px; font-weight:600; padding:5px 11px`。確定ツールのピルと「未判別」ピルは配色を分ける（未判別は破線枠）。

### タグで絞り込み（アコーディオン）

軸は **ジャンル / その他タグ の2軸**。見出し右に「管理」リンク（タグ管理モーダルを開く）。**ジャンル軸は既定展開、その他タグ軸は既定折りたたみ。**

- 軸見出しは**キャレット（▸/▾）＋軸名テキストのみ**。色付きの四角マーカーは置かない — 値行のチェックボックスと色がかぶって「チェック済み」に見えるため撤去された
- 値の行は `padding:5px 10px 5px 28px; border-radius:8px; font-size:13px`。左に**チェックボックス**（`15×15` 角丸4px。OFF は白地＋枠、ON はアクセント塗り＋白いチェック）、右に件数（等幅）
- **チェックの色は一律アクセント紫で、タグ色とは無関係**
- 候補は**全語彙基準**で並べる。どのゲームにも付いていない（count 0 の）タグも表示される

### 設定ボタン / 取り込みボタン（最下部）

- **設定**（取り込みボタンの上）: セカンダリスタイル（透明背景＋枠、角丸 `11px`、padding `10px`、歯車アイコン）
- **フォルダを取り込む**: 全幅、ダーク背景＋白文字 weight 700 14px、角丸 `11px`、padding `12px`、フォルダアイコン付き。hover でアクセント背景

## メインヘッダー

- **左**: ビュー名（22px / weight 800、ビューに連動）＋ 件数（等幅 14px）
- **中**: 検索ボックス（最大幅 `300px`、白背景、角丸 `9px`、左に虫眼鏡、プレースホルダ「タイトル・タグで検索…」）。**タイトルとタグ名の両方**を部分一致で即時フィルタする。大文字小文字は区別しない
- **右**: 表示トグル（pill 状のセグメント、`テーブル` / `ギャラリー`。アクティブは白背景＋薄い影）

## 統計バー

4指標を横並び（gap 22px）。各指標は ラベル(11px weight 600) ＋ 数値(等幅 22px) ＋ 単位(12px)。

`総ゲーム数`（本） / `総容量`（GB） / `お気に入り`（本） / `未整理`（タグ0件の本数）

**いずれも全ゲーム基準で算出する**（検索やフィルタの結果には連動しない）。

## 持たない情報

**「プレイ時間」と「進行状況（プレイ中 / クリア等）」は持たない。** どちらも取得にはプロセス監視が必要で、ゲームを起動したあと終了を待ち受ける常駐処理を抱えることになるため採用しない。列・バッジ・統計・ソートキーのいずれにも出さない。

進行状況を記録したい場合は**その他タグ**として手で付ける（専用の列は設けない）。ゲームの起動は exec するだけでプロセスを監視しない（[`data-flow.md`](../architecture/data-flow.md)）。

## ツールバー

`display:flex; padding:0 26px 14px` ＋ 下境界。ボタンは4つで、いずれもドロップダウンを開く。

**制作ツール** / **タグ** / **並び替え** / **グループ**

ボタンは `flex-shrink:0` かつラベルを `white-space:nowrap` にする（フィルタ適用時に潰れて折り返すのを防ぐため必須）。基本形は白背景＋枠＋角丸8px＋padding `6px 11px`＋13px。メニューを開いている間・条件を適用中は淡いアクセント背景＋アクセント文字に変わる。

- **制作ツール** — 属性ピル群のポップオーバー。**サイドナビの制作ツールセクションと同一状態を共有**する。適用中は件数バッジ（丸）と独立した「解除」を持つ
- **タグ** — ジャンル / その他タグの2軸を並べたポップオーバー（min-width 250px、最大高 360px でスクロール）。**サイドナビのタグ絞り込みと同一状態を共有**する。適用中は件数バッジと独立した「解除」を持つ
- **並び替え** — `追加日` / `タイトル` / `サイズ`（選択中にチェック）。矢印（`↓`/`↑`）または「並び順を反転」で昇順/降順をトグル。テーブル・ギャラリー両方に即反映
- **グループ** — `なし` / `ジャンル` / `制作ツール`。選択するとグループ見出し（ラベル＋件数＋区切り線）付きで表示する。制作ツールでのグループ化では未判別のゲームが「未判別」グループに入る

メニューはメニュー外クリックで閉じる（全画面の透明オーバーレイで捕捉）。

**適用中の条件チップ行**は、条件があるときだけ区切り線に続けて表示する（× で個別解除＋「すべて解除」）。この行は `flex-wrap:wrap` の**別グループ**にまとめて4つのボタンを圧迫しないようにする。制作ツールのチップは属性バッジ調、タグのチップは従来のタグ色チップで描く。

## カバーの既定表示

ユーザー指定画像も抽出アイコンも無いときの既定カバーは、**id ベースの手続き的な淡色グラデーション**（`linear-gradient(150deg, a, b)` を8組で循環）＋中央に薄く重ねた**ゲームパッドのアウトライン SVG**。

グリフのサイズと濃度は場所ごとに変える（テーブルのサムネ 16px / ギャラリーカード 46px / ドロワーのバナー 60px）。淡色背景なので**濃色**で描く。値は [`design-tokens.md`](../reference/design-tokens.md) を参照。

```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5">
  <rect x="2" y="7" width="20" height="10" rx="5"/>
  <path d="M7 12h-2M6 11v2M15 11.5h.01M18 13.5h.01"/>
</svg>
```

**カバーが淡色なので、カバー上に載る文字と下グラデーションは反転させる**（白文字ではなく主文字色を使う）。ギャラリーのお気に入り☆と制作ツールオーバーレイは暗い半透明ピルのままで、淡色上でも視認できる。

ユーザー指定画像がある場合は `center/cover no-repeat` で優先表示する。exe から抽出したアイコン（ファイル名が `_icon.png` で終わる）は解像度が低いため**全面に引き伸ばさず、既定グラデーションの上に中央表示**する。カバーの供給経路は [`data-flow.md`](../architecture/data-flow.md) を参照。

## テーブル表示（既定）

CSS Grid。列テンプレート（ヘッダー・各行で共通）:

```
grid-template-columns: 40px minmax(150px,1fr) 118px minmax(160px,1.3fr) minmax(150px,1fr) 74px 86px 60px;
/*      [カバー]    タイトル      制作ツール        タグ              保存先          サイズ 追加日 操作 */
```

- **ヘッダー行**: `padding:11px 26px`、11px weight 700 letter-spacing .08em、下境界つき、`position:sticky; top:0; z-index:2`
- **グループ見出し行**（グループ化時のみ）: ラベル(weight 700 13px)＋件数(等幅)＋伸びる区切り線。`position:sticky; top:37px`
- **データ行**: `padding:8px 26px`、下境界つき、`cursor:pointer`、hover で白背景。**行クリックで詳細ドロワーを開く**

各セル:

| 列 | 内容 |
|---|---|
| カバー | `34×34` 角丸 `7px`＋影。正方形（アプリアイコンの比率に合わせる） |
| タイトル | weight 700 14px（1行省略）＋直下に実行ファイル名（等幅 11px） |
| 制作ツール | 属性バッジ。確定はレンチアイコン＋実線枠、未判別は「?」アイコン＋**破線枠**でラベル「未判別」 |
| タグ | **1行固定・折り返さない**（下記）。制作ツールは含めない |
| 保存先 | フォルダアイコン＋パス（等幅 11px、1行省略） |
| サイズ | 右寄せ 等幅 12px |
| 追加日 | 右寄せ 等幅 11px（`YYYY/MM/DD`） |
| 操作 | お気に入り☆トグル ＋ 起動▷ボタン（`28×28` 角丸7px） |

☆と起動は行クリック（詳細オープン）を `stopPropagation` で止める。起動するとトーストが出る。

実体が見つからないゲームには「見つかりません」バッジが付く（[`storage-integrity.md`](storage-integrity.md)）。

### タグ「1行固定」の実装指針

- コンテナ: `display:flex; gap:5px; align-items:center; min-width:0; overflow:hidden;`（折り返さない）
- 各タグチップ: `flex:0 1 auto; min-width:0; max-width:150px; overflow:hidden; text-overflow:ellipsis; white-space:nowrap;`
- 「+N」チップ: `flex:0 0 auto;`（縮まず常に表示）
- 上限はテーブル・ギャラリーとも **2件＋「+N」**。全タグは詳細ドロワーで確認・編集する
- タグ0件のときは破線チップ「＋ タグ」（クリックで詳細ドロワー）

## ギャラリー表示

グループごとに5列グリッド（`repeat(5,1fr)`, gap 18px, padding `22px 26px`）。カード:

- **カバー**: `aspect-ratio: 1/1`（正方形）、角丸 `12px`＋影。hover で `translateY(-3px)`＋影を強調
- カバー上の要素: 下部に白系のグラデーション、左下にタイトル（weight 700 13px・主文字色）、右上にお気に入り☆（暗い半透明ピル）、**左上に制作ツールのオーバーレイ**（暗い半透明ピル＋blur、白文字 10.5px/700、レンチアイコン）
- **カバー下のキャプション行**: タグ（最大2＋「+N」、1行省略）＋右端にサイズ（等幅 11px）。`min-height: 24px` を付けて**タグの有無でカード全高がずれないよう固定**する
- **カード全体のクリックで詳細ドロワー**を開く

## 詳細ドロワー

テーブル行 / ギャラリーカードのクリックで、右から幅 `400px` の白いドロワーがスライドインする。

暗幕クリックまたは ✕ で閉じる（本体クリックは伝播を止める）。

上から順に:

1. **カバーバナー**（`16/10`。ヘッダー用途なので正方形化の対象外）＋下グラデーション＋右上✕＋左下タイトル（23px weight 800）
2. **アクション** — `起動`（primary）/ `フォルダ`（secondary）。どちらもトーストを出す
3. **制作ツール**ブロック（下記）
4. **タグ**ブロック（下記）
5. **情報リスト** — `実行ファイル` / `保存先`（アクセント色・等幅・`word-break:break-all`）/ `サイズ` / `追加日`

実体が見つからないゲームでは警告バナーと保存先の再指定導線が出る（[`storage-integrity.md`](storage-integrity.md)）。

### タイトルの編集（バナー左下）

- 通常時: タイトル文字の右に**鉛筆アイコン**（16px, opacity .75）。タイトル文字またはアイコンのクリックで編集モードへ
- 編集時: 同じ位置に**インライン入力**（白背景 .97、角丸9px、padding `9px 12px`、weight 800 18px、`autoFocus`）＋右にアクセント色の**✓保存ボタン**（`42px` 角丸9px）
- 確定は **Enter** または ✓（トースト「タイトルを変更しました」）、取消は **Esc**。**空文字は保存せず取消扱い**
- 変更後のタイトルはテーブル・ギャラリー・検索・起動トーストのすべてに反映される。**元のフォルダ名・保存先パスは変更しない**（表示名のみの上書き）

### カバー画像の変更（バナー左上）

- **「画像を変更」ボタン**（カメラアイコン＋ラベル、高さ32px 角丸9px、暗い半透明＋backdrop-blur）。クリックで画像ファイル選択ダイアログを開き、選んだ画像をカバーに反映する（トースト「カバー画像を変更しました」）
- カスタム画像が設定されているときだけ、右に**↺リセットボタン**（`32×32` 角丸9px 同スタイル）。押すと既定の淡色グラデーションに戻る（トースト「カバー画像を初期に戻しました」）

選択画像はアプリの設定フォルダへコピーして `games.cover_path` に保存し、`/covers/` 経由で配信する。詳細は [`app-api.md`](../reference/app-api.md) の `SelectCoverImage` / `ResetCover`。

### 制作ツールの変更

アクションボタンとタグブロックの間に置く。

- 現在値をピル（レンチ＋ラベル）で表示した行（薄い面背景＋枠、角丸 `10px`、padding `9px 12px`、右に「▾ 変更」）
- クリックでドロップダウン。選択肢は `["未判別", <既定ツール6種>, <ライブラリ内に存在する全ツール>]` を重複排除したもの。**既定ツール6種** = `RPGツクール` / `Unity` / `WOLF RPG` / `ティラノ` / `GameMaker` / `Godot`
- 選択中の項目にチェック。選ぶと `SetTool` を呼んで即反映＋トースト「制作ツールを変更しました」
- **「未判別」から確定へ持っていく主動線がここ**
- 現在値が未判別でも、この行のスタイルは中立に保つ（破線にしない）

### タグの追加・削除・色変更

- 現在のタグをチップで表示する。各チップは**ラベル部分のクリックで色ピッカーを開き**、末尾の `×` で削除する
- **色ピッカー**: チップ直下のポップオーバー。「「<タグ名>」の色」見出し＋**9色のスウォッチ**（5列グリッド、各 `24×24` 角丸7px、塗りは各色の文字色）。選択中は黒＋白の二重リングでハイライト。クリックで即適用、外側クリックで閉じる
- 入力欄（プレースホルダ「タグを入力して Enter で追加…」）で **Enter で新規タグを追加**
- 入力文字列が既存タグに無い場合は「＋「<入力>」を新しいタグとして追加」リンクを出す
- 「既存タグから追加」: ライブラリ全体のタグから、未付与かつ入力に部分一致するものを最大10件 `＋ ラベル` の候補チップで出す → クリックで即追加
- 追加・削除・色変更は即時反映（テーブル・統計・タグ件数も連動）
- **制作ツールはここに含めない**

### タグの色システム

- 色は**タグ名ごとにグローバル**。同じタグを持つ全ゲームで同色になる
- 未設定タグの**既定色**は所属軸で決まる: **ジャンル → blue / その他 → gray**
- ユーザーは色ピッカーから9色パレットで変更できる。パレットの値は [`design-tokens.md`](../reference/design-tokens.md) を参照
- **サイドナビ・フィルタのチェックボックスはタグ色と紐づけない**（一律アクセント紫）。軸見出しに色付きの四角も置かない

## タグ管理モーダル

タグの語彙そのものを管理する。制作ツールと違い、ジャンル・タグは**ユーザーが増やす / リネームする前提**なので、新規登録・リネーム・性質変換の導線が必要になる。

**導線**は2つ。サイドナビ「タグで絞り込み」見出し右の「管理」リンクと、設定モーダル「ライブラリ」節の行。

中央モーダル（幅 `560px`）。上部にタブ「ジャンル / その他タグ」（件数バッジ付きのセグメントコントロール）。

各タグ行:

- 左に**色ドット**（クリックでパレット展開、9色から選択）
- ラベルクリックまたは鉛筆アイコンで**インラインリネーム**（Enter 確定 / Esc 取消）。リネームは**付与済みの全ゲームに反映**される。空名・別タグとの重複は拒否（マージはしない）
- **⇄ 性質変換アイコン**: ジャンル行なら「その他タグにする」、その他タグ行なら「ジャンルにする」。色は維持される
- **ゴミ箱アイコンで削除**（インライン確認「〇本から削除しますか？」→「削除する」）。タグ行そのものが消え、全ゲームから外れる
- 右側に使用件数

下部に**新規登録欄**（タブに応じてプレースホルダが変わる）。既存と重複する名前は登録できない（トースト通知）。登録するとマスター語彙に追加され、**どのゲームにも未割当のまま**、詳細ドロワーのタグ候補とフィルタ軸に即座に出現する。

対応する API は `RenameTag` / `SetTagColor` / `SetTagAxis` / `DeleteTag` / `CreateTag`（[`app-api.md`](../reference/app-api.md)）。タグの軸とライフサイクルの規則は [`data-model.md`](../reference/data-model.md) を参照。

## 設定モーダル

中央モーダル（幅 `520px`、角丸 `18px`）。ヘッダー「設定」＋✕。

- **ライブラリ**セクション: 「登録ゲーム数」「総容量」の情報行（等幅）＋ タグ管理モーダルへの導線
- **危険な操作**セクション: ダンジャーカード（枠＋淡い赤背景、角丸 `14px`、padding `18px`）。左にゴミ箱アイコンタイル（`38×38` 角丸10）、見出し「すべてのデータを消去」(15px/800)、説明文（`line-height:1.65`）

説明文は「登録ゲーム・タグ・お気に入り・カバー画像・制作ツールの変更などを削除して初期状態に戻します。**ゲーム本体のフォルダやファイルには一切影響しません。**この操作は取り消せません。」

**二段階確認**にする:

1. ボタン「すべてのデータを消去…」
2. 押下で確認パネルが展開: 「確認のため `消去` と入力してください。」＋テキスト入力＋「キャンセル」「完全に消去する」
3. **入力が `消去` に完全一致するまで実行ボタンは無効**（無効時は `cursor:not-allowed`）

実行すると DB の全行（games / tags / game_tags、採番もリセット）と `covers/` ディレクトリを削除して初期状態に戻し、ビュー・検索・フィルタもリセットしてモーダルを閉じ、トースト「すべてのデータを消去しました」を出す。

**ゲーム本体のフォルダ（`folderPath` 配下）には絶対に触らない — アプリの不変条件。** 実装は `ResetLibrary()`（[`app-api.md`](../reference/app-api.md)）。

## フォルダ取り込みモーダル

「フォルダを取り込む」から中央モーダル（幅 `560px` 角丸18px）を開く。3ステップ。

- **drop** — 破線のドロップゾーン（角丸14px、hover でアクセント枠＋薄いアクセント背景）。フォルダアイコン、「ゲームフォルダをドラッグ&ドロップ」、「フォルダを選択」ボタン、補足「配下の .exe を自動検出します（RPGツクール / Unity / Godot / WOLF RPG など）」。**実際のドラッグ&ドロップと、ダイアログからの選択の両方に対応する**
- **scanning** — 回転スピナー＋「スキャン中…」。調べるフォルダが**2つ以上**のときは、Go 側の `scan:progress` イベント（[`app-api.md`](../reference/app-api.md) の「取り込み」）を受けてスピナーの代わりに**プログレスバー＋「N/M フォルダを確認中…」＋現在のフォルダ名**を出す（総数1は進みを表現できないためスピナーのまま）
- **review** — 「N件のゲームが見つかりました。」＋検出カード（チェックボックス `20×20` 角丸6px、選択でアクセント塗り＋✓、行の枠と背景も変化）。各カードは タイトル / `フォルダ＋実行ファイル`（等幅）/ **制作ツールのバッジ** を表示する。フッターは「キャンセル」＋「**N本を取り込む**」

### 閉じる操作（誤クローズ防止）

- **drop** ステップは暗幕クリックまたは ✕ で即閉じる（詳細ドロワー等と同じ）
- **scanning / review** 中の暗幕クリック・✕ は即閉じせず、モーダル内オーバーレイで確認を挟む — scanning では「スキャンを中断しますか？」、review では「検出結果を破棄しますか？」＋「続ける / 閉じる」。時間のかかったスキャンの結果を誤クリック1つで失わないため
- review フッターの「キャンセル」は明示操作なので確認なしで閉じる
- 閉じても Go 側のスキャン処理そのものは中断されない（結果が破棄されるだけ。バックエンドのキャンセル機構は持たない）

検出カードの制作ツールは、確定なら確定バッジ、判別できなければ**破線の未判別バッジ**＋補足「（取り込み後に設定できます）」を出す。取り込み後は未判別も含めて `tool` を保存する。

処理の詳細シーケンスと exe 検出のロジックは [`import-flow.md`](../processes/import-flow.md) を参照。

## トースト通知

下部中央。ダーク背景＋白文字 weight 600 14px、角丸12px、約 **2.2s** で自動消滅。

文言例: 「「<タイトル>」を起動します…」「フォルダを開きます： <パス>」「タイトルを変更しました」「制作ツールを変更しました」「すべてのデータを消去しました」。

API が失敗したときもトーストで知らせる（[`app-api.md`](../reference/app-api.md) の「エラーの扱い」）。

## 絞り込みの評価順と AND/OR 規則

**適用順**: `ビュー` → `タグ` → `制作ツール` → `検索` → `並び替え` → `グループ`

タグの評価は次のとおり。

- **ジャンル × ジャンル = OR**（複数選択でどれかに一致すれば表示）
- **その他タグ × その他タグ = OR**
- **ジャンル群 と その他タグ群 の間 = AND**

```
tagOk(game) =
  (selectedGenres.length === 0   || selectedGenres.some(g => game.labels.includes(g)))
  &&
  (selectedOtherTags.length === 0 || selectedOtherTags.some(t => game.labels.includes(t)))
```

**制作ツールは完全に独立したフィルタ**で、複数選択は OR（1ゲーム=1ツールのため）。タグとは AND で併用する。

検索はタイトルとタグ名の部分一致で、大文字小文字を区別しない。統計（総数 / 総容量 / お気に入り / 未整理）は**絞り込みに連動せず全ゲーム基準**で算出する。

規則の根拠と撤回された旧仕様は [`tag-filter.md`](tag-filter.md) を参照。

## UI 状態

フロントの状態は `LibraryPage.tsx` に集約する（[`overview.md`](../architecture/overview.md)）。

| 状態 | 型 |
|---|---|
| 表示形式 | `'table' \| 'gallery'` |
| 検索文字列 | `string`（タイトル＋タグ名の部分一致） |
| ビュー | `'all' \| 'fav' \| 'untagged'`（＋実体不明があるとき `'missing'`） |
| タグフィルタ | 選択中のタグ（ジャンル群・その他タグ群を区別して保持） |
| 制作ツールフィルタ | `toolFilters`（複数選択 OR） |
| 軸の開閉 | 軸ごとの boolean（ジャンルは既定 true、その他タグと制作ツールは既定 false） |
| 並び替え | `'added' \| 'title' \| 'size'` ＋ `'asc' \| 'desc'` |
| グループ | `'none' \| 'genre' \| 'tool'` |
| 開いているメニュー | `'tool' \| 'tag' \| 'sort' \| 'group' \| null` |
| ドロワー対象 | ゲーム ID または null |
| 色ピッカー対象 | タグ名または null |
| モーダル | 取り込み（＋ステップ `'drop' \| 'scanning' \| 'review'`）/ タグ管理 / 設定 |
| トースト | 文字列または null |

**ゲーム・タグの実データは状態ではなく DB が正**で、`App.tsx` が `games` / `allTags` として保持し `refresh()` で取り直す。編集操作は楽観的更新にして、失敗時は `refresh()` で巻き戻す（[`data-flow.md`](../architecture/data-flow.md)）。並び替え・グループ・フィルタ・軸の開閉といった一時的な UI 状態は永続化しない。

## プロトタイプと実装の対応

原本のプロトタイプは独自の `.dc.html` 形式で、状態を `localStorage` に保存し、カバー画像を data URL で保持する。**実装ではこれらを SQLite と `covers/` ディレクトリに置き換えている**。

| プロトタイプ | 実装 |
|---|---|
| `localStorage` の `favs` / `tagsMap` / `tagColors` / `titleMap` / `coverMap` / `toolMap` / `imported` | SQLite の `games` / `tags` / `game_tags`（[`data-model.md`](../reference/data-model.md)） |
| カバーの data URL | `games.cover_path` ＋ `/covers/` 配信 |
| ジャンル ＝ タグ配列の先頭要素 | `tags.axis` 列（`genre` / `other`）を `SetTagAxis` で変更 |
| スキャンを約 1.4s の擬似待機で再現 | `internal/scan` による実際の走査 |
| 「3件のゲームが見つかりました」（固定） | 実際の検出件数 |
| データ全消去は `localStorage` の削除 | `ResetLibrary()`（DB 全行＋`covers/`。ゲーム本体は不可侵） |

原本には Mac / クロスプラットフォーム想定と書かれているが、実装のターゲットは Wails v2（Windows 配布・WSL2 開発）である。
