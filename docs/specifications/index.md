# Concepts

* [ライブラリ画面 UI 仕様（現行）](library-screen.md) - 画面・インタラクション・状態の単一の正典。基本ハンドオフと調整版ハンドオフを統合したもの。
* [制作ツールは一級属性として扱う](tool-attribute.md) - タグではなく Game.tool の属性。判別できないものは「未判別」を一級状態として保存する。
* [タグは genre / other の2軸でユーザーが手で付ける](tag-taxonomy.md) - 軸・色・語彙管理とタグ行のライフサイクル。
* [絞り込みの AND/OR 規則と適用順](tag-filter.md) - ジャンル同士 OR・その他タグ同士 OR・両群間 AND。制作ツールは独立フィルタで OR。
* [exe の自動検出と制作ツールの推定](exe-detection.md) - 何をゲームと見なし、どの .exe を本命として選ぶか（3層の判定）。
* [保存先の整合性は検出して知らせるが自動削除はしない](storage-integrity.md) - 実体消失の検出・保存先の再指定・自動削除しない原則。
